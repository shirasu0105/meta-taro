# 00_PRD.md

# Product Requirements Document

## 1. プロダクト概要

### プロダクト名

Metaたろう

### コンセプト

League of
Legendsの初心者〜中級者が、チャンピオン選択〜ロード画面の短時間で対面知識を得られるAIアドバイスサービス。

## 2. 背景

既存サービスは統計中心であり、「なぜ有利なのか」「どう立ち回るべきか」を短時間で理解しづらい。
本サービスは統計情報とAIを組み合わせ、実践的なアドバイスを提供する。

## 3. ビジネス目標

-   2027年1月までのいずれかの月で月間利益3万円
-   利益＝広告収入＋課金収入−API料金
-   新規追加費用の累積赤字5万円以内

## 4. ターゲット

-   日本サーバー
-   ゴールド〜プラチナ
-   ソロ／デュオ
-   ノーマルドラフト

## 5. MVP

-   通常レーン検索（**TOP / MID のみ対応**。2026-08-07）
-   ~~BOT(4体)検索~~ → **当面スコープ外**（2026-08-07。実装は `docs/archive/bot/` に退避）
-   AI有利不利
-   立ち回り
-   注意スキル
-   パワースパイク
-   推奨ルーン
-   推奨サモナースペル
-   推奨ビルド
-   SEOページ
-   検索履歴

> **勝率は初版のスコープ外**とする。統計データの取得方式が未確定であり、
> AIが生成した数値を統計値として表示することは避けるため（09_data_pipeline.md §2）。
> 統計ソース確定後に復活させる（判断は 05_tasks.md の T-1308）。

> **対応レーンを TOP / MID に限定した**（2026-08-07）。アドバイスの量と品質にリソースを集中するため。
> JG / ADC / SUP は検索画面で「準備中」と表示し、量が揃った時点で解放する。

## 6. AI方針

-   初版は事前生成のみ
-   統計取得は将来フェーズ。初版の有利不利はチャンピオン知識にもとづくAI判断
-   リアルタイムAIは将来導入検討
-   **生成方式は対外発信で説明しない**（プロンプト・LLM・生成ロジックを含む）。LP・UI・法務ページ・広告審査のサイト説明などで訴求文句にしない。**リポジトリ上の秘匿はしない**（リポジトリは public のまま `scripts/prompts/` も追跡を継続する。2026-08-08 に方針明確化。09_data_pipeline.md §3.4）
-   **生成品質は P13（要素技術開発）で確立する** — 評価指標と真値の定義・モデル選定・RAG等の技術選定を経て、
    API化の可否を T-1308 で判断する
-   **ユーザーフィードバックを次回生成へ還流させる**（P15）。アドバイスが使われるほど品質が上がる構造にする
