## 3. 共通コンポーネント

- **ヘッダー**: 左からロゴ（gold枠の「対」+「Metaたろう」+ Cinzel `LOL MATCHUP COACH`）、ナビ（できること / 使い方 / 用語集）、右端に Patchバッジ（monospace `Patch {patch} · JP`）。LPのみ右端にCTA「対面を検索する」
- **フッター**: 利用規約 / プライバシーポリシー / 免責事項 リンク + 注意書き「本サービスはRiot Games公式ではありません。AI・統計情報は参考情報であり、勝利を保証するものではありません。」+ `Patch {patch} · JP · {updatedAt} 更新 · アイコン: Data Dragon`
- **パネル**: `border: 1px solid border` + `bg-panel`、内側の区切りは `border-subtle`
- **セクション見出し**: 日本語見出し（text-hi, 700）+ Cinzel英字マイクロラベル（gold, 8.5px, letter-spacing 2px）を横並び（例: 「要約 SUMMARY」「詳細立ち回り GAME PLAN」「注意スキル DANGER」）
- **星評価**: ★5個並び。点灯=gold、消灯=star-off。下に「有利 · 5段階中4」等のラベル
- **勝率表示**（**Phase 1では非表示**）: teal大数字（%）+ tealゲージバー（トラック=inset）+ 注記。統計ソース未整備のため現在は描画しない。`components/ui/WinRateBar.tsx` は温存し、`winRate` が提供された時点で復活する（§7 / [09_data_pipeline.md](./09_data_pipeline.md) §2）
- **チャンピオンアイコン**: 正方形、border 1px（自分側=gold / 相手側=border）、角丸2px
- **役割バッジ**: 「あなた」「自チーム」「ADC」= teal枠、「相手」「敵チーム」= danger枠。小型（9〜10px, 800）
- **用語チップ**: teal文字 + teal半透明枠のリンク。結果画面下部に「用語:」に続けて並べ、用語集へ遷移

## 4. 画面仕様

### 4.1 LP（`/`）

1. **ヒーロー**: 右側にチャンピオンスプラッシュ（グラデーションでネイビーに溶かす）。Cinzel `AI MATCHUP ADVICE` → 見出し「ロード画面の30秒で、対面がわかる。」→ 説明文 → goldCTA「対面を検索する」+「無料 · 登録不要 · 毎週パッチごとに更新」
2. **結果プレビューカード**: ヒーロー右に MID アーリ vs アニー のミニカード（アイコン、星、有利不利ラベル、要約冒頭）
3. **できること FEATURES**: 3カード（01 AI評価を5段階で先に / 02 危険スキルとパワースパイク / 03 ルーン・スペル・ビルド推奨）
4. **使い方 HOW TO**: 3ステップ（レーンを選ぶ → チャンピオンを入力 → 結果を見る）
5. フッター

### 4.2 検索（`/search`）

- タブ2つ: **通常レーン** / **BOT（2v2）**（下線タブ。アクティブ=gold文字+gold下線）
- **通常レーンタブ**:
  - レーン選択: TOP / JG / MID の3ボタン（選択中=gold枠+薄gold背景）。注記「ADC / SUP は「BOT（2v2）」タブへ」
  - 自分のチャンピオン / 相手のチャンピオン の2ペイン（PC横並び・モバイル縦積み）
  - チャンピオン入力: テキストフィールド（フォーカス=teal枠）+ 候補ドロップダウン（アイコン+日本語名+英語名、選択行はteal薄背景）。注記「ひらがな・カタカナ・英語で検索できます」
  - 選択済み表示: アイコン+名前+「×」で解除。「よく使う:」リンク列（履歴由来）
  - 実行ボタン: 2体確定で活性（gold）「この対面で結果を見る」/ 未確定時は注記「自分と相手の2体が確定すると表示できます」
  - **最近の検索**: 直近の検索履歴チップ（アイコン2つ+「MID · アーリ vs アニー」形式、クリックで結果へ）。localStorage・直近10件
- **BOTタブ**:
  - 選択状況バー: 「選択状況 [====  ] 3 / 4」（goldゲージ）+ 注記「4体すべて確定すると結果を表示（事前生成データ）」
  - 自チーム（gold見出し）/ 敵チーム（danger見出し）の2パネル × 各 ADC / SUP スロット。未選択スロットは破線枠「＋ クリックして選択」
  - 4体確定まで実行ボタンは無効表示（例「残り1体（敵SUP）を選択してください」）+ 注記「該当データがない組み合わせは「データがありません」を表示」

### 4.3 通常レーン結果（`/matchups/{lane}/{me}-vs-{enemy}`）

- パンくず「‹ 検索に戻る」+ タイトル「対面結果」+ レーンバッジ（gold枠）+ 右端にパッチ・更新日
- **VSパネル**: 自分（gold枠アイコン+「あなた」teal バッジ）vs 相手（「相手」dangerバッジ）、中央に Cinzel `VS`
- **評価パネル**: 左=AI評価（星5段階 + 「有利 · 5段階中4」）、縦区切り、右=注記「AI評価はチャンピオン相性とスキル構成にもとづくAIの判断です。統計上の勝率ではありません。」。**390pxでも横並びを維持する**（3列グリッド）
  - `winRate` が提供された場合のみ: 右=勝率（teal大数字+ゲージ+注記）、注記はパネル下部へ移動（Phase 2）
- 以下2カラム(PC)/縦積み(モバイル):
  - 左: **要約 SUMMARY**（本文、用語はtealリンク）→ **詳細立ち回り GAME PLAN**（序盤/中盤/終盤のgold枠バッジ+本文）

- **パワースパイク**: 自分/相手 × 序盤/中盤/終盤 の ◎○△ マトリクス（◎=濃teal or 濃danger、○=淡、△=グレー）+ 一言注記
- **推奨セット**: キーストーン（丸アイコン+gold枠）+「メイン: 栄華 / サブ: 天啓」+ サモナースペル2つ → コアビルド3品（1品目gold枠、`›` 区切り、品名）+ 靴 → 状況対応アイテム+理由

### 4.4 BOT結果（`/matchups/bot/{...}`）

- 通常結果と同構成だが: VSパネルはペア2アイコン重ね（「あなた側」/「相手側」バッジ）、バッジは「BOT 2v2」、評価パネル注記「評価は4体の組み合わせに対するAIの判断です。立ち回りは下の視点トグルで切り替え。」
- **視点トグル**: 「ADC視点 · ジンクス」「SUP視点 · スレッシュ」の2ボタン（アクティブ=teal系強調）+ 注記「立ち回り・注意スキル・推奨セットが視点ごとに切り替わります」
- トグル配下に視点別の 要約 / 注意スキル / パワースパイク / 推奨セット / 用語チップ（データは `views.adc` / `views.sup`）

### 4.5 用語集（`/glossary`）

- ヘッダーナビ「用語集」から遷移。用語（text-hi・700）+ 説明（本文色）のリスト。各用語に `id` アンカー（結果画面の用語チップ・リンクから `/glossary#all-in` 形式で遷移）

### 4.6 データなし

- 対面ページと同レイアウト内に「データがありません」パネルを表示（当該対面のアドバイスが未生成である旨 + 検索へ戻るCTA）
  - **統計の不足を理由にしない。** Phase 1 は統計を一切持たないため、「十分な統計データがない」と書くと
    他の対面には統計があるという誤解を与える（§7 / [09_data_pipeline.md](./09_data_pipeline.md) §2）
- `noindex` を必ず設定（04_api §3）

| 対象 | 仕様 |
|---|---|

### 6.1 IME（日本語入力）対応

チャンピオン入力欄（`components/search/ChampionPicker.tsx`。通常レーン・BOT両タブで共用）の必須仕様。

| 要件 | 内容 |
|---|---|
| 変換中はドロップダウンを出さない | `compositionstart`〜`compositionend` の間は候補ドロップダウンを描画しない。確定と同時に開く |
| 変換中のキー操作を奪わない | `keydown` は `isComposing` **かつ** `keyCode === 229` を併用して判定し、変換中は Enter / ↑ / ↓ / Escape を一切処理しない |
| 候補件数のフィードバック | 変換中は入力欄の**上**（ラベル行）に「候補 N件」を表示して補う |

**設計理由**: WindowsのIME予測変換ウィンドウはキャレット位置に描画されるOSレベルのオーバーレイであり、
Webコンテンツより常に上位にある。`z-index` や `position: fixed` では重なりを解消できないため、
**衝突を避ける（変換中は出さない）**方針をとる。ドロップダウンを入力欄の上に出す案は、
IMEも下に余白がなければ上に回り込むため390pxで再衝突し、採用しない。

`isComposing` 単独では不十分（変換確定のEnterで `false` になるブラウザ・IMEの組み合わせがある）。
これを怠ると**変換確定のEnterがチャンピオン選択も実行してしまう**。

## 7. 確定済みデザイン判断

- **AI評価は星5段階（★）で確定**。プロトタイプのTweaksにあるグレード表示（A/B/C）は不採用
- **勝率は初版で非表示**（統計ソース未整備。[09_data_pipeline.md](./09_data_pipeline.md) §2）。プロトタイプは勝率ブロックを含むが、**これはプロトタイプに対する意図的な差分**である。§1「プロトタイプが正」の例外として本項を優先する。Phase 2 で統計を導入した時点で復活させる
- テーマは HEXTECH DARK 1案のみ（ライトテーマなし）
- プロトタイプ内のドメイン表記 `taimen-coach.jp`・URL `/result/...` は仮。実URLは 02_architecture §6 に従う
